# Client credit links: plan and draft messages

**Nothing here has been sent.** These are drafts for you to send yourself,
from your own WhatsApp or email, to clients you have a good relationship with.

## What a credit link is worth (honestly)

- It tells people, search engines and AI tools that you built a real, live
  site, which is useful evidence and entity association.
- It can send referral visits from people who like the client's site.
- It is **not** a ranking switch. Google's spam policies name "widely
  distributed links in the footers or templates of various sites" as a
  pattern it can discount, especially with keyword-stuffed anchor text. So:
  - Use your **name** as the anchor ("Website by Xerxes Duane"), never
    "best web design Dubai".
  - One link per site. A footer credit or an About/Credits page mention is fine.
  - No payment or discount in exchange for the link. If a client asks for one,
    the link must be `rel="sponsored"` or `rel="nofollow"`.
  - If the client says no, that is fine. Do not ask twice.

## The snippet to send

```html
<a href="https://www.xerxesduane.com/">Website by Xerxes Duane</a>
```

For clients with a case study, swap the `href` for their case-study URL from
the table.

## After a yes

1. Add the snippet (or the client adds it).
2. Note the date in the lead log's notes, so any referral enquiries can be
   traced back to it.
3. A few weeks later, check Search Console → Links → *Top linking sites*.
